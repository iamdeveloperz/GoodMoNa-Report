## 5. 운영 현황 (2026-11-15 확인)

| 확인 | 결과 | 판단 |
| --- | --- | --- |
| `GET https://goodmona.hsdevs.com/healthz` | 200, 0.46초 | 서버·터널 정상 |
| `GET /api/import/files` (외부) | 403 | 가져오기 외부 차단 정상 |
| `GET /api/patients` (로그인 없이) | **200** | 최신 코드라면 401이어야 함 |
| `GET /login` | **404** | 02 인트라넷이 아직 배포되지 않음 |

**결론: 운영 서버는 로그인 연동(커밋 `a1b2799`) 이전 버전입니다.** 지금 운영 주소는 로그인 없이 환자 API가 열려 있습니다(현재는 예시 데이터만 있음). 리포 루트의 `deploy/install-all.ps1`(02 → 01 순서, 관리자 권한)로 재배포하면 최신 코드의 로그인·권한이 적용됩니다. 재배포 전에는 실제 환자 데이터를 넣지 않습니다.

## 6. 한계와 남은 과제

| 구분 | 내용 | 영향 | 대응 |
| --- | --- | --- | --- |
| 기능 | **CRM 자동 제출 미구현** | 원장 소견을 CRM에 다시 입력해야 함 | [CRM 연동 방안](crm-integration.md) §3 공통 기반(약 5.5일)을 먼저 구현해 텍스트 복사로 운영, CRM 확인 후 어댑터 추가 |
| 운영 | 운영 서버가 최신이 아님 | 로그인 없이 API 접근 가능 | `deploy/install-all.ps1` 재배포 |
| 운영 | 자동 백업 없음 | PC 디스크 고장 시 데이터 손실 | `C:\GoodMoNa\01\data`를 매일 다른 디스크·NAS로 복사하는 예약 작업 (SQLite는 `VACUUM INTO`로 일관된 사본) |
| 운영 | PC 한 대가 단일 장애 지점 | PC가 꺼지면 전체 중단 | 자동 시작·재시작으로 완화, UPS 권장. 규모가 커지면 서버 이전 |
| 데이터 | 운영 설정에서 예시 데이터(`SeedDemoData`)가 켜져 있음 | 실데이터와 섞일 수 있음 | 실제 환자 데이터 입력 전 끄고 DB 초기화 |
| 품질 | Whisper 의료 용어 인식률 미측정 | 오인식이 기록에 남을 수 있음 | 실제 소견 녹음 표본으로 오류율 측정, 프롬프트 용어 보강, CRM 제출 전 원장 확인 단계 |
| 보안 | 환자 기록 열람 기록(감사 로그) 없음 | 누가 어떤 기록을 봤는지 추적 불가 | 조회 API에 열람 로그 추가 |
| 보안 | Cloudflare Access 미적용 | 로그인 화면이 인터넷에 노출 | 필요 시 Access 추가(촬영 경로 제외) |
| 확장 | SQLite 단일 파일 | 동시 쓰기가 많아지면 대기 | 병원 1곳 규모에선 충분. 여러 지점이면 PostgreSQL로(EF 공급자 교체) |
| 사진 | HEIC 미지원(가져오기) | 아이폰 원본 파일은 변환 필요 | 폰 촬영 경로는 브라우저가 JPEG로 변환하므로 영향 없음 |
| 테스트 | 화면 자동 테스트 없음 | 화면 회귀를 사람이 확인 | §4 체크리스트, 필요 시 Playwright로 카메라 없는 흐름부터 |

## 7. 회고

잘 된 점

- **프로세스 하나 + SQLite 파일 하나**로 API·실시간·음성 변환·가져오기를 묶어 배포가 스크립트 한 번으로 끝납니다.
- 음성 인식을 로컬 GPU로 돌려 **비용 0원·외부 전송 0건**으로 1~2초 안에 스크립트가 나옵니다.
- 오래 걸리는 작업을 **대기열 + 202 + SignalR 상태**로 통일해, 녹음·가져오기·(앞으로의) CRM 제출이 같은 모양이 됩니다.
- 경합 상황(변환 중 삭제, 동시 업로드, QR 재발급)을 테스트로 재현해 두어 고쳐도 다시 깨지지 않습니다.

아쉬운 점과 개선

- CRM 정보를 과제 초기에 확인하지 못해 R11을 설계로 남겼습니다. 외부 시스템 연동은 착수 전에 상대 시스템 정보([CRM 연동 방안](crm-integration.md) §8 질문지)를 먼저 받는 것이 필요합니다.
- 배포 스크립트의 Windows 특유 문제(PowerShell 5.1 인자 따옴표, cloudflared 응답 형식)에 시간이 들었습니다. 해결 내용은 `docs/architecture.md`의 "알려진 함정"에 남겼습니다.
- 운영 반영을 코드 커밋과 따로 진행하다 보니 운영 버전이 뒤처졌습니다. 배포 후 `/healthz`에 커밋 해시를 함께 돌려주면 운영 버전을 바로 확인할 수 있습니다.
