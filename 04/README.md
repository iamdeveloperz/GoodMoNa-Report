## 결론 요약

- **AI마다 보는 곳이 다릅니다.** 네이버 AI 브리핑은 네이버 블로그를, ChatGPT·Gemini는 자체 도메인·공공기관을, 구글 AI 개요는 유튜브를 많이 인용합니다. 지금 공식 사이트(goodmona.co.kr)의 "DR.칼럼"에는 글이 없고 네이버 블로그 링크뿐이라, ChatGPT·Gemini 쪽에서 인용될 원천이 없습니다.
- **① 기반 정비(1~2주)**: 구조화 데이터(의원·의사), llms.txt의 최상급 표현 빼기, 병원 정보(이름·주소·전화) 모든 채널 통일, 랜딩을 공식 도메인 아래로.
- **② 양질의 글**: 환자가 실제로 묻는 질문 하나에 글 하나. 첫 문단에 답 → 수치·출처·원장 소견 → 의료광고 점검 → 원장 승인. 공식 사이트(원본) + 네이버 블로그(재구성), 주 1~2편.
- **③ 자동화**: 원장 유튜브 대본을 원천으로 AI 초안 → 자동 점검 → 원장 승인(10분) → 발행. 02(승인된 자료)·03(받아쓰기·표현 점검·승인 흐름) 재사용. 네이버는 글쓰기 API가 2020년 종료되어 발행은 사람이 붙여넣기(로그인 자동화는 계정 제재 위험).
- **측정**: 질문 30개를 5개 AI에 월 1회 — 굿모나 언급률·인용 출처·틀린 정보.
