# GoodMoNa Report

GoodMoNa 병원 경과 보고 시스템(PMS) 과제 모음입니다. 폰으로 찍고 보고하면, 원장 iPad에 바로 뜹니다.

| 폴더 | 과제 | 상태 |
| --- | --- | --- |
| [`01/`](01/) | ① 보고 흐름: 환자 검색 → 방문 생성 → QR → 폰 촬영 → 실시간 표시 → 보고 | 완료 · https://goodmona.hsdevs.com |
| `02/` | ② 원장 흐름: 알림 → 녹음 → 텍스트 변환(STT) → 자막 | 예정 |

기술 스택: ASP.NET Core (.NET 10) Minimal API · SignalR · EF Core + SQLite · Vite + TypeScript · Cloudflare Tunnel
