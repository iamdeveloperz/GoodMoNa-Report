## 결론 요약

쇼츠는 조회는 잘 나오지만(634편, 누적 약 1,289만 회), 조회가 큰 주제는 샴푸·약국템이고 병원 핵심인 모발이식 쇼츠는 가장 덜 봅니다(중앙값 3,700). 쇼츠에서 상담으로 가는 클릭 경로가 없고, 어떤 영상이 상담을 만들었는지 재는 장치도 없습니다.

권장: ① 측정 장치(랜딩 분석 태그·UTM·상담 접수 유입 질문) → ② 쇼츠 '관련 동영상' → 롱폼 → 상담 랜딩 연결 → ③ 유입형 50 · 연결형 30 · 전환형 20 비중으로 재배분 → ④ 주간 리뷰. 목표 지표를 조회수에서 **유튜브발 상담 신청 수**로 바꿉니다.

## 자동화 결론

가능합니다. 이 채널 쇼츠는 원장 단독 출연 + 큰 자막 형식이라 컷·자막·세로 맞춤·제목 초안·업로드를 자동화할 수 있습니다. 권장은 **반자동**: 리포에 있는 Whisper(01)·로컬 AI(02)·GPU 서버로 초안을 자동 생성하고, 기획(대본 카드)과 최종 승인(의료광고 책임)만 사람이 합니다. 1단계 2주 → 2단계 롱폼→쇼츠 추출 → 3단계 예약 업로드·성과 수집.

## 데이터 재현

1. 채널 쇼츠 탭을 브라우저로 엽니다.
2. F12 → 콘솔에 `tools/collect-shorts.js` 내용을 붙여 넣고 실행합니다.
3. 콘솔에 요약 표가 나오고, 전체 목록은 클립보드에 복사됩니다(스프레드시트에 붙여 넣기).

공개 화면 값만 읽습니다. YouTube Studio 지표(시청 유지, 트래픽 소스)와 상담 데이터는 보고서 §6의 확인 필요 항목입니다.
